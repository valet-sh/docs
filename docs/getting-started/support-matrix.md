# Support Matrix

valet.sh is currently working on the following operating systems:

| Operating-System         | valet.sh 3.x                            |
|--------------------------|-----------------------------------------|
| Ubuntu 24.04             | :fontawesome-solid-check:{ .check-mark } |
| Ubuntu 26.04             | :fontawesome-solid-check:{ .check-mark } |
| macOS 26 (Apple Silicon) | :fontawesome-solid-check:{ .check-mark } |
| macOS 27 (Apple Silicon) | :fontawesome-solid-check:{ .check-mark } |

!!! Info
    valet.sh 3.x only supports Apple Silicon on macOS - Intel Macs are no longer supported.
