# Installation

!!! Info "Migration from valet+"
    If you are migrating from valet+, please migrate with the *[macOS Upgrade Guide guide](../how-to-articles/migrate-from-valet-plus-to-valet-sh.md)*.


## Install valet.sh

``` bash
bash <(curl -fsSL https://raw.githubusercontent.com/valet-sh/install/3.x/install.sh)
```


Reopen your terminal and install all services and tools via

``` bash
valet.sh install
```
