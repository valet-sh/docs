# Init

## Description

Creates a .valet-sh.yml file in the current directory.
See also the *[init-instance](init-instance.md)* command to generate a plain configuration file and the *[Project configuration via .valet-sh.yml](../how-to-articles/project-configuration-via-valet-sh-yml.md)* guide.


## Usage

``` bash
valet.sh init
```
